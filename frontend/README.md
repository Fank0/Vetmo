# Frontend (Agent 6) — 2 окна

## Окно 1. Оверлей (`overlay.html` + `overlay.js`)
Компактная панель поверх игры: слева меню Radiant, справа меню Dire, в центре — кто хорошо играет против введённого героя (счёт backend).
- Вбить героя → контрпики пересчитываются сами (debounce 350мс).
- Переключатель «Radiant пикает / Dire пикает».
- Одна кнопка **☰ Меню** → главное меню.
- Прозрачность — ползунок в Настройках меню.
- Поверх Dota 2: OBS → Browser Source `http://localhost:8080/overlay.html` — или F11 в браузере в оконном режиме игры.

## Окно 2. Главное меню (`index.html` + `app.js`)
4 вкладки: **⚔ Драфт** (пики/баны 5+баны, поиск, роли, контрпики, объяснения), **🏆 Топ героев** (`GET /meta/top` — винрейт из database), **📰 Новости** (`GET /news`), **⚙ Настройки** (backend URL, лимит, прозрачность оверлея + как повесить оверлей).

## Данные
Герои и статистика — только из database через API. Портреты — Steam CDN по `npc`-имени из `/heroes`, с fallback на инициалы без сети. Счёт — только `scoring.py`; UI цифр не считает (проверяется тестами).
